# Examples

This directory contains example files, test data, and reference materials.

## Contents

- **G-Code Files**: Example G-code files (`.gcode`)
- **DXR Files**: Example DXR files (`.dxr`)
- **PDF Documentation**: KUKA-CNC syntax reference (`Syntax Gcode KUKA-CNC.pdf`)
- **Images**: Screenshots and example geometry images
- **Icons**: Duplicate icon files (originals in `Resources/`)

- `Example.gcode` - Sample G-code file
- `DXR_2512031344_Home_1.21kg_24min.dxr` - Example DXR file

- `Bildschirmfoto 2025-12-04 um 10.22.00.png` - Screenshot
