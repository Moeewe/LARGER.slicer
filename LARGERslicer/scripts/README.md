# Scripts

This directory contains Python scripts for icon generation and other utilities.

## Icon Generation Scripts

- `generate_designer_svg_icons.py` - Generate designer-style SVG icons
- `generate_gh_icons.py` - Generate Grasshopper component icons
- `generate_pattern_icons.py` - Generate pattern-specific icons
- `generate_professional_svg_icons.py` - Generate professional SVG icons

## Usage

Run scripts from the project root directory:

```bash
python scripts/generate_designer_svg_icons.py
```
