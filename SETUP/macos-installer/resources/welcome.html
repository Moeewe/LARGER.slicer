LARGER.slicer für Rhino und Grasshopper

Dieses Programm richtet LARGER.slicer für Rhino 8 und Rhino 7 ein, je nachdem, was auf diesem Mac installiert ist:

  • LARGER.slicer (aus diesem Paket, oder neuer vom Rhino-Paketserver)
  • Robots und Pufferfish vom Rhino-Paketserver (nur für die erste Fassung der Hausdefinition nötig)
  • die Roboterbibliothek des KUKA KR120 der FH Münster

Bitte Rhino vorher beenden. Eine Internetverbindung wird gebraucht. Das Programm kann jederzeit wieder laufen; Aktuelles bleibt, Älteres wird erneuert.

For Rhino 9: drag the file largerslicer-…-rh9_0-any.yak from the release onto the Rhino window, or use the PackageManager.
