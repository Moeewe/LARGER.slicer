Die Bahn kreuzt sich nie.

Sonst pflügt die Düse durch frisches Material. Geht ein Muster nicht ohne Kreuzung, gewinnt die Kreuzungsfreiheit.

Jede Lage liegt flach.

Der Wechsel zur nächsten passiert über eine kurze Rampe, immer an derselben Stelle.

Höchstens eine halbe Bahn daneben.

Jede Bahn braucht die darunter. Überhang ≤ atan(½ Breite ÷ Lagenhöhe)

Gleiches F in jeder Zeile.

Gleichmäßige Geschwindigkeit, unabhängig von der Segmentlänge. Und nie F0.

Lagen müssen nicht waagerecht sein.

Für gebogene Lagen wird das Modell geradegebogen, geschnitten und zurückgebogen. Alles andere funktioniert gleich.
