01

Installieren

Drei Wege. Der erste richtet alles auf einmal ein und ist für die Maschinen der FH Münster gedacht.

Empfohlen

SETUP-Paket mit Installer

Installiert LARGER.slicer, das Robots-Plug-in und Pufferfish über den Rhino-Paketmanager und kopiert die Bibliothek des KUKA KR120. Kann jederzeit wieder laufen, dann wird nur Veraltetes erneuert.

  1. Paket ladenLARGERslicer-SETUP.zip herunterladen und entpacken.
  2. Rhino schließen, Installer startenWindows: Doppelklick auf Install Windows.bat. Mac: Rechtsklick auf Install Mac.command, dann zweimal Öffnen.
  3. Rhino in Millimetern öffnenGrasshopper starten und die Definition aus dem Ordner SETUP öffnen, oder im Tab LARGER mit Quick Start beginnen.
SETUP-Anleitung
Nur das Plug-in

Rhino-Paketmanager

In Rhino den Befehl PackageManager eingeben (deutsches Rhino: PaketManager), nach LARGERslicer suchen, installieren und Rhino neu starten. Updates kommen auf demselben Weg.

Ohne Internet an der Maschine: Die Datei .yak für deine Rhino-Version aus dem Release laden und auf das Rhino-Fenster ziehen.

.yak-Dateien im Release
Von Hand

Die .gha-Datei

Für Rechner, auf denen kein Paket installiert werden darf. Die .yak-Datei ist ein ZIP-Archiv: umbenennen, entpacken, alle Dateien aus dem Ordner für dein System nehmen, nicht nur die .gha.

  • Rhino 9 (Paket rh9_0): Windows net8.0-windows, Mac net8.0
  • Rhino 8 (Paket rh8_0): Windows net7.0-windows, Mac net7.0
  • Rhino 7 (Paket rh7_0): die Dateien ganz oben im Archiv

In Grasshopper unter File, Special Folders, Components Folder ablegen. Unter Windows vorher in den Eigenschaften jeder Datei „Zulassen“ anklicken. Alte Kopien entfernen, sonst erscheinen Bausteine doppelt.

Grasshopper 2 (Vorschau, Rhino 9) wird noch nicht über den Paketmanager verteilt. Wie man es lädt, steht in der Anleitung zur Grasshopper-2-Version.

Was sich geändert hat

Kurz und auf Deutsch. Die vollständige Liste steht im Changelog (Englisch).

Nächste
in Arbeit
In Entwicklung

Düsen, Roboterzelle, eigene Maschinen

  • Externe Achsen: Schiene und Drehtisch fahren mit dem Druck mit. In Rhino getestet, an einer Steuerung noch nicht.
  • Düse wählen: Bahnbreite und Lagenhöhe passend zur eingeschraubten Düse, aus den Weber-Profilen und der Einstellung der FH Münster. Eine Warnung, wenn Bahn und Düse nicht zusammenpassen.
  • Easy Slicer kann alles: Düse, Boden- und Deckmuster, gekippte Lagen, Start- und Endlagen, Brücken, massive Teile.
  • Einstellungen am Baustein: Auswahl, Zahlen, Schalter und Knöpfe sitzen direkt am Baustein. Speichern schreibt die Datei einmal pro Klick.
  • Für 45 Grad: Opferlagen vor und nach dem Bauteil, die danach abgefräst werden. Brücken verbinden innere und äußere Wände, damit die Düse nicht absetzt.
  • Design Rules: Was Bahnbreite und Düse erlauben, bevor du modellierst, mit Wandstärken für zwei Bahnen und Fräsaufmaß.
  • Eigene Maschinen und Zellen: .machine-Dateien und Druckzellen als Rhino-Datei. Maschine und Zelle erscheinen in 3D.
  • Erste Lage und Bett: eigene Höhe für die erste Lage. Eine Bahn im Bett oder zu tief darüber wird gemeldet.
  • Roboter: Simulation des Drucks, Kollisionsprüfung mit allen Gliedern, Werkzeugrichtung wie im Robots-Plug-in, Anfahrt von oben, Brim.
  • Korrigiert: zu viel Material auf gebogenen Lagen, falsche Lagenmarken im DXR, Lagenzahl gerundet statt aufgerundet, ein Absturz in Grasshopper 2.
1.3.0

Release folgt

Roboter-Tab und Easy Slicer

  • Roboter-Tab: Robot, Robot Tool, Robot Cell und Robot Program. Das Werkzeug folgt der Bahn, auch gekippt und mehrachsig. Prüft Reichweite, Achsen, Singularitäten und Achsgeschwindigkeit, schreibt KRL und die Zeilen für den DXR Generator.
  • Easy Slicer: ein Baustein vom Modell zur geprüften Bahn, mit Bericht.
  • Ginger G-code: G-Code in Originalgröße für den Ginger One.
  • Desktop Test Print: eigener Start- und Endcode für Bambu Lab, Prusa, Creality und Elegoo.
  • Print Bed: zeigt das Bett der Maschine und prüft, ob die Bahn darauf passt. Quick Start legt fünf Beispiele auf ein Bett.
  • Speichern: ohne Pfad landet die Datei auf dem Schreibtisch.
  • Korrigiert: Dezimalpunkt im DXR auf deutschen Rechnern, fehlende Lagen im DXR-Kopf, springende Wendepunkte an runden Öffnungen.

Der Slicer-Tab

  • Neu gebaut: Print Settings, Slice, Walls, Bottom Fill, Continuous Path, Round Corners, Start and End, Path Check. Alles wird eine Linie.
  • Infill aus einer Linie: Stege, Waben und Gitter, Welle, Fachwerk und Mäander, Kammerwand, eigene Linien.
  • Gebogene Lagen: entlang einer Führungsfläche (non-planar) oder senkrecht zu einer Kurve (multiaxial).
  • Machine Profile für Weber DXR, Ginger und Filament, Desktop Test Print für den Tischdrucker.
  • Path Check prüft Auflage und Kreuzungen. Der Vorschub bleibt in jeder Zeile gleich, F0 kommt nicht mehr vor.
  • Läuft in Rhino 9. Neues Logo.
